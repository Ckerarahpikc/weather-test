# Weather App (Test Project)

![React](https://img.shields.io/badge/React-61DAFB?logo=react&logoColor=black)

 A simple React weather application that shows the main difference between old and new React.

## 🪶 Features 🪶
* **Live Forecasts:** Search and display current weather conditions (e.g., checking the temperature in Taiwan or globally).
* **API Integration:** Efficiently fetches and serves external weather data.
* **Clean UI:** A straightforward interface for visualizing forecasts.
* **DIY:** `starter.js` file is responsible to carrying the main part of the weather logic. You can just create your own interface.

## 🛠️ Requirements 🛠️
To run this project locally, you will need:
* [Node.js](https://nodejs.org/) installed on your machine.

## 🧧 Building from Source (For Developers) 🧧
If you want to view the code, run it in your own environment (like LazyVim or IntelliJ), or contribute, follow these steps:

1. **Clone the repository:**
```bash
	git clone git@github.com:Ckerarahpikc/weather-test.git
```

2. **Navigate to the directory:**
```bash
	cd weather-test
```

3. **Install the dependencies:**
```bash
	npm install
```

4. **Start the development server:**

> This will start the `AppModern.js`, to render the other file you'll have to change the `index.js` file.
```bash
	npm start
```
